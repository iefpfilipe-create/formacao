UC 00605

Programar para a web, na vertente servidor (server-side)

Programa e Objetivos

Apresentação da Unidade

Esta unidade de competência capacita para o desenvolvimento de aplicações web no lado do servidor (server-side), cobrindo a arquitetura cliente-servidor, a criação de conteúdos dinâmicos, a manipulação de pedidos HTTP, a integração e gestão de bases de dados relacionais via SQL, a gestão de sessões e autenticação, bem como a implementação de mecanismos de segurança, depuração e documentação técnica.

Conhecimentos Base

  • Arquitetura Web Server-Side: Conceitos fundamentais, modelo cliente-servidor, protocolo HTTP/HTTPS e ciclo de vida de pedidos e respostas.
  • Linguagens e Tecnologias Server-Side: Sintaxe, estruturas de controlo e ecossistemas para programação no servidor (Node.js, PHP, Python, Java ou C#).
  • Geração de Conteúdo Dinâmico: Processamento de dados no servidor, motores de templates e resposta em formatos HTML, JSON e XML.
  • Interface e Gestão de Bases de Dados: Conexão a SGBD (MySQL, PostgreSQL, etc.), comandos SQL (CRUD - Select, Insert, Update, Delete) e ORM.
  • Gestão de Sessões e Estado: Cookies, sessões de utilizador, autenticação, autorização e controlo de acessos.
  • Serviços Web e APIs: Arquitetura REST/RESTful, tratamento de rotas, cabeçalhos HTTP e consumo/disponibilização de dados.
  • Segurança Server-Side: Prevenção de vulnerabilidades (SQL Injection, XSS, CSRF), validação e sanitização de dados de entrada.
  • Testes, Depuração e Logs: Ferramentas de depuração de scripts no servidor, gestão de erros e registos de execução (logging).
  • Normas, Documentação e Privacidade: Guiões técnicos, manuais do utilizador, RGPD e boas práticas no tratamento de dados sensíveis.

Aptidões Práticas

  • Reconhecer as tecnologias web do lado do servidor e distinguir código server-side de client-side.
  • Aplicar conceitos e técnicas de programação para a web na vertente servidor.
  • Utilizar elementos e a sintaxe de uma linguagem de scripting server-side para criar conteúdo dinâmico.
  • Utilizar ferramentas de acesso e integração com bases de dados.
  • Utilizar SQL em consultas, inserção, modificação e eliminação de dados (CRUD).
  • Configurar a saída de dados da base de dados para apresentação no browser ou disponibilização via API.
  • Implementar mecanismos de autenticação e gestão de sessões de utilizador de forma segura.
  • Identificar e corrigir erros de execução e sintaxe em scripts server-side.
  • Criar um guião técnico, documentação ou manual de utilizador do programa desenvolvido.

Critérios de Desempenho

Desenvolver aplicações web no lado do servidor (server-side):

  • Identificando e corrigindo erros de execução, lógica e sintaxe em scripts no servidor.
  • Estabelecendo a ligação segura e eficiente entre o script server-side e a base de dados.
  • Garantindo o correto processamento de pedidos dinâmicos e a segurança no tratamento de dados.
  • Elaborando a documentação técnica necessária e assegurando a conformidade com os requisitos definidos.
